A fast reference for terms used throughout SplitRE and its documentation. For the full walkthroughs behind each concept, follow the linked guide.

**Agent Net** — What an agent actually takes home from a deal: their share of the splittable amount, minus their own deductions (E&O, transaction fees, etc.). See [Creating a Commission Plan](/docs/creating-commission-plans).

**Amendment** — A corrected version of a confirmed deal. Amending creates a new deal record linked back to the original, which stays in your history for an audit trail. See [Entering and Managing Deals](/docs/entering-and-managing-deals).

**Breakdown Snapshot** — The frozen calculation record locked into a deal the moment it's confirmed. Later changes to a commission plan never retroactively change an already-confirmed deal's numbers. See [Entering and Managing Deals](/docs/entering-and-managing-deals).

**Broker Cut (Broker Net)** — The portion of GCI the brokerage keeps, after commission plan rules and any cap limit are applied. See [Creating a Commission Plan](/docs/creating-commission-plans).

**Cap** — The maximum dollar amount a brokerage collects from a single agent in a calendar year. Once hit, the agent keeps everything (or pays only a flat post-cap fee) for the rest of the year. See [Setting Up Agent Caps](/docs/setting-up-agent-caps).

**Cap Ledger** — The running, deal-by-deal record of how much broker cut has been collected from each agent in a given year — this is what SplitRE checks before calculating whether an agent has hit their cap. See [Setting Up Agent Caps](/docs/setting-up-agent-caps).

**Cap Opening Balance** — The amount of broker cut already collected from an agent before they were added to SplitRE, used so mid-year joiners' cap tracking starts accurate instead of at $0. See [Setting Up Agent Caps](/docs/setting-up-agent-caps).

**Cap Year** — The calendar-year window (resets every January 1) used for cap tracking, determined by a deal's closing date rather than the date it was confirmed. See [Setting Up Agent Caps](/docs/setting-up-agent-caps).

**Closing Date** — The date a deal closed, editable by the broker and defaulting to today. It determines which cap year a deal counts against. See [Entering and Managing Deals](/docs/entering-and-managing-deals).

**Commission Plan** — The reusable template that defines how a deal is calculated for any agent assigned to it: the split, the cap, and any deductions. See [Creating a Commission Plan](/docs/creating-commission-plans).

**Confirmed** — The deal status meaning a deal's numbers are locked into a breakdown snapshot and the agent has been emailed their commission breakdown. See [Entering and Managing Deals](/docs/entering-and-managing-deals).

**Counter Gate** — A commission plan rule that applies an extra fee only to an agent's first N deals (for example, a mentorship fee on their first 3 closings). Counts deals in confirmation order, not closing order. See [Creating a Commission Plan](/docs/creating-commission-plans).

**Deal Override** — A one-off customization (referral %, relocation %, bonus, custom deduction) applied to a single deal rather than the whole commission plan. Gets frozen into that deal's breakdown snapshot once confirmed. See [Creating a Commission Plan](/docs/creating-commission-plans).

**Draft** — The deal status before confirmation. Drafts can be freely edited and don't count toward an agent's cap yet. See [Entering and Managing Deals](/docs/entering-and-managing-deals).

**Flat Deduction** — A fixed dollar amount subtracted either off the top (before the split) or from the agent's share (after the split) — for example, an E&O insurance fee. See [Creating a Commission Plan](/docs/creating-commission-plans).

**GCI (Gross Commission Income)** — The starting number every calculation works from: sale price × commission percentage. See [Creating a Commission Plan](/docs/creating-commission-plans).

**Percentage Deduction** — A percentage of GCI taken off the top before the agent/broker split is applied — for example, a franchise royalty fee. See [Creating a Commission Plan](/docs/creating-commission-plans).

**Plan Override** — A per-agent adjustment to their assigned commission plan's split, cap, or deductions, without needing to create a separate plan just for them. See [Creating a Commission Plan](/docs/creating-commission-plans).

**Split** — The agent/broker percentage division applied to the splittable amount — for example, a 70/30 split. Must always total 100%. See [Creating a Commission Plan](/docs/creating-commission-plans).

**Splittable Amount** — What's left of the GCI after off-the-top deductions (franchise fee, referral %, relocation %, flat/percentage deductions) are subtracted — this is the number the split percentage is actually applied to. See [Creating a Commission Plan](/docs/creating-commission-plans).

**Team Split** — A commission plan rule type for agents who split commission within a team, rather than 1:1 against the brokerage.

**Voided** — The deal status for a deal that's been reversed. Voiding a confirmed deal reverses its contribution to the agent's cap ledger for the year. See [Entering and Managing Deals](/docs/entering-and-managing-deals).
